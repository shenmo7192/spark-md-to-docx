# 文件格式要求
- 使用 `[密级]` 标记密级（如：`[密级]公开`），此标记独占一行，放在大标题前
- 使用 `[大标题]` 标记大标题（如：`[大标题]关于开展2026年度工作的通知`），此标记独占一行
- 使用 `#` 表示一级标题，`##` 表示二级标题，`###` 表示三级标题，`####` 表示四级标题。不要写序号，工具会自动编号（一级：一、二、三、…；二级：（一）（二）（三）…；三级：1. 2. 3.…；四级：（1）（2）（3）…）
- 正文直接输入文字，每行作为独立段落，工具会自动首行缩进两字符
- 使用 `**文字**` 表示加粗
- 使用 `*文字*` 表示斜体
- 使用 `文字` 表示下划线
- 有序列表使用 `数字. 内容` 格式（如：`1. 第一项`）
- 无序列表使用 `- 内容` 格式（如：`- 项目内容`）
- 表格使用标准 Markdown 表格格式：
  |列1|列2|列3|
  |---|---|---|
  |内容|内容|内容|
- 需要右对齐的内容（如落款、日期）使用 HTML 语法：`
部门名称
日期
`
- 所有中文标点统一使用全角符号（，。；：（）！？），但阿拉伯数字后的小数点、逗号保持半角

# 公文格式标准
- 纸张：A4，上边距 3.5cm，下边距 3.3cm，左边距 2.8cm，右边距 2.6cm
- 密级：三号黑体，左对齐，行距 28 磅
- 大标题：二号方正小标宋简体，居中，行距 35 磅
- 正文：三号仿宋_GB2312，首行缩进 2 字符，两端对齐，行距 28 磅
- 一级标题：三号黑体，行距 28 磅
- 二级标题：三号楷体_GB2312，行距 28 磅
- 三级标题：三号仿宋_GB2312 加粗，行距 28 磅
- 四级标题：三号仿宋_GB2312，行距 28 磅
- 页码：四号半角宋体阿拉伯数字，格式 " - 1 - "，奇偶页不同
